# Your backgrounds

Everything in this folder stays on this machine. It is ignored by git, so bought or licence-restricted packs are safe here.

- Drop in PNG or WebP images. Any size works; they are scaled and letterboxed to 1280x720 at render time. 16:9 sources look best.
- Subfolders become categories in the background picker, so `forest/`, `school/` and so on will show up as groups.
- Keep any licence file that came with a purchased pack alongside the images.

CC0 backgrounds that ship with the repo live in `web/backgrounds/` instead.
